# Designs and implementation records

This directory preserves the reasoning behind Black Box's development. It is an engineering
archive, not the current installation guide or an authoritative list of unfinished work.

- `specs/` contains dated designs. A design can be exploratory, partly implemented, or superseded.
- `plans/` contains implementation steps and, in many cases, observed verification results.
  An unchecked box is a snapshot of the document, not proof that the work remains open today.

Read dates and later corrections carefully. Commands, routes, defaults, test counts, and module
names may describe an earlier version. Machine-specific paths in historical examples identify the
original development context; substitute your own checkout and consult current commands before use.
No document here authorizes changes to an installation or a cloud account.

Start with the [documentation index](../README.md) for current guides, the
[release notes](../releases/v0.2.0.md) for a published artifact, and the
[project history](../evolution.md) for a curated narrative. Task-board and runner designs are
separately preserved in the [retired-feature archive](../history/retired-board/README.md).
